# Usage savings with fixed acceptance criteria

Read only when an explicit savings request or observed waste makes it relevant.
This is an execution method, not a model benchmark or a mandate to install a service.

## Adopt: reduce redundant inputs

When a progress document has a self-contained current section followed by completed
phases, a read-only helper can return the current section verbatim and point to the
full history. Include the product purpose, active decisions, evidence paths, failures,
remaining checks, approval/budget limits and next action. Read task-specific source
next; retrieve historical reasoning when it affects the current decision. If the
format is unknown, fail visibly and read the source rather than silently truncating.

Keep required validation. Reuse successful results only when their inputs and relevant
conditions are unchanged. Scripts can perform exact counting, hashing, geometry
constraints and assertions; a probabilistic judge adds no value to those operations.
Do not rerun broad inventories or reopen accepted phases without new evidence.

## Conditional: cheaper model or decision-model integration

First identify work that will actually leave the expensive model's context or calls.
Adding a classifier while the parent still re-evaluates everything is not a saving.
Test a representative bounded task against the existing method with the same inputs
and acceptance criteria. Record accepted outputs, missed requirements, false alarms,
retries, review/integration effort, elapsed time and observed model usage when exposed.
Do not add a compulsory benchmark to routine mechanical work or run a model tournament.
Retain a deterministic fallback or the capable current route when results are uncertain.

For 3D workflows, distinguish asset creation, scene composition, runtime character
decisions and coding. A faster scene composer does not prove equivalent geometry,
materials, art direction, headset performance or lower development-token usage.
Preserve stable authored landmarks when the product depends on spatial memory.

## Evidence boundary — reviewed September 22, 2026

A local document-reading check reduced returned UTF-8 text from 114,158 source bytes
to 5,404 output bytes (about 95.3%) by returning the product introduction, reference
index and current checkpoint instead of complete documents. Assertions verified the
current phase and preserved-reference index were retained verbatim, historical phases
were excluded, and current limits remained. Alternate-working-directory and invalid
argument handling also passed. No external model was called for this extraction.

This demonstrates less supplied text on that read, not measured token savings,
subscription-credit savings, latency improvement or non-inferior end-to-end quality.
Targeted follow-up reads consume additional context. Nothing was deleted. Required
source inspection and acceptance checks still determine whether the result is good.
No comparative Jev, Luna, Sol or Astra trial was run as part of this observation.

Revisit the method if the current section is stale/incomplete, required historical
constraints are repeatedly missed, or total rereading offsets the initial reduction.
