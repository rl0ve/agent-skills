## August 1 Wall-Clock Addendum

The live DeepSWE leaderboard now reports wall-clock duration directly. Under the fixed mini-swe-agent harness, GPT-5.6 Luna Max scores 67.2% at $0.61/task and averages 18.7 minutes, while GPT-5.6 Sol Medium scores 61.1% at $1.86/task and averages 7.1 minutes. Luna Max therefore wins this comparison on score and cost, while Sol Medium finishes about 2.6 times faster ([DeepSWE](https://deepswe.datacurve.ai/)).

The native Codex measurements point in the same speed direction: Luna Max averages 8.00 minutes and Sol Medium 5.17 minutes per task. Artificial Analysis defines this as active agent wall time and excludes environment startup, verifier, judge, and other harness overhead ([Artificial Analysis](https://artificialanalysis.ai/agents/coding-agents)).

Do not infer time from steps. DeepSWE separately reports 101.7 mean steps for Luna Max and 30.9 for Sol Medium, but measured durations, not step counts, should drive timeliness routing.

## 0. Naming check (the user's terms are real, with two caveats)

- **Luna / Sol / Terra are official OpenAI public names**, not aliases. OpenAI launched the GPT-5.6 family to general availability on July 9, 2026 with "our new flagship, **Sol**, alongside **Terra**, a balanced model for everyday work, and **Luna**, our most cost-efficient model," describing them as "durable capability tiers that can advance on their own cadence" ([OpenAI, GPT-5.6](https://openai.com/index/gpt-5-6/)).
- **Claude Sonnet 5, Claude Opus 5 and Claude Fable 5 are all real, current Anthropic models** with API names `claude-sonnet-5`, `claude-opus-5` and `claude-fable-5` ([Anthropic models overview](https://docs.claude.com/en/docs/about-claude/models/overview)).
- **Caveat 1 — "Sol Ultra" is a setting, not a model.** `ultra` is a reasoning/effort mode that "goes further by coordinating four agents in parallel by default" ([OpenAI, GPT-5.6](https://openai.com/index/gpt-5-6/)); in Codex it appears as a `model_reasoning_effort` value ([OpenAI Codex subagents docs](https://developers.openai.com/codex/subagents/)). There is no separate "Sol Ultra" model ID or price.
- **Caveat 2 — "AGI-3" = ARC-AGI-3.** Confirmed: OpenAI and Anthropic both report ARC-AGI-3 results, and ARC Prize publishes verified scorecards for GPT-5.6 and Claude Opus 5 ([ARC Prize, GPT-5.6](https://arcprize.org/results/openai-gpt-5-6); [ARC Prize, Claude Opus 5](https://arcprize.org/results/anthropic-claude-opus-5)). Section E covers this in detail.
- **Caveat 3 — the OpenAI docs model index is stale.** The legacy `platform.openai.com/docs/models` page still lists GPT-5.2 as the featured model and does not include GPT-5.6 ([OpenAI models page](https://platform.openai.com/docs/models)); the current model pages live at `developers.openai.com`. Treat the legacy page as out of date.

## A. Executive synthesis — 12 decision-relevant findings

1. **A July 30, 2026 price cut reshaped the cost ladder.** Luna dropped 80% to **$0.20 in / $1.20 out** per 1M tokens and Terra 20% to **$2.00 in / $12.00 out**; Sol is unchanged at **$5 / $30** ([OpenAI, Advancing the price-performance frontier](https://openai.com/index/advancing-the-price-performance-frontier-with-gpt-5-6/)). Any routing table built before July 30 is mispriced by up to 5×.

2. **Reasoning effort, not model tier, is the dominant latency lever.** On Artificial Analysis, GPT-5.6 Sol goes from **4.57 s** time-to-first-token at medium ([AA, Sol medium](https://artificialanalysis.ai/models/gpt-5-6-sol-medium)) to **12.49 s** at high ([AA, Sol high](https://artificialanalysis.ai/models/gpt-5-6-sol-high)) to **133.04 s** at max ([AA, Sol max](https://artificialanalysis.ai/models/gpt-5-6-sol)). Same model, same price, ~29× latency spread. Claude Opus 5 shows the same shape: **6.52 s** medium → **15.97 s** high → **92.02 s** max ([AA, Opus 5 medium](https://artificialanalysis.ai/models/claude-opus-5-medium); [AA, Opus 5 high](https://artificialanalysis.ai/models/claude-opus-5-high); [AA, Opus 5 max](https://artificialanalysis.ai/models/claude-opus-5)).

3. **The "Luna Max beats Sol Medium" claim is not supported by any source found.** Every effort-matched comparison found goes the other way: Artificial Analysis Intelligence Index **Luna max 51** ([AA, Luna max](https://artificialanalysis.ai/models/gpt-5-6-luna)) vs **Sol medium 54** ([AA, Sol medium](https://artificialanalysis.ai/models/gpt-5-6-sol-medium)); AA Coding Agent Index in Codex **Luna max 59** vs **Sol medium 61** ([AA, Claude Code vs Codex](https://artificialanalysis.ai/agents/coding-agents/comparisons/claude-code-vs-codex)); ARC-AGI-2 **Luna max 59.5%** vs **Sol medium 67.1%**, ARC-AGI-3 **Luna max 0.18%** vs **Sol medium 1.07%** ([ARC Prize, GPT-5.6](https://arcprize.org/results/openai-gpt-5-6)). The nearest real published crossover is **Luna Max vs *Terra* Medium** on GeneBench-Pro (16.5% vs 13.6%), and even that author calls it statistically indistinguishable and 3× more expensive on output ([aicoding.am analysis](https://aicoding.am/blog/gpt-5-6-model-tier-reasoning-depth)). Section on this in E/F below. **Do not route on this claim.**

4. **Luna is dramatically cheaper per unit of coding work, but it is not a Sol substitute.** In Codex, Luna medium costs **$0.09/task** at Coding Agent Index 42, Luna max **$0.31** at 59, Sol medium **$2.99** at 61, Sol max **$7.08** at 67 ([AA, Claude Code vs Codex](https://artificialanalysis.ai/agents/coding-agents/comparisons/claude-code-vs-codex)). Luna max is ~23× cheaper than Sol max for ~88% of the index.

5. **Luna has a hard long-context cliff.** On OpenAI MRCR v2 8-needle, Sol scores 91.5% and Terra 89.6% at 256K–512K, while **Luna scores 41.3%** ([OpenAI, GPT-5.6](https://openai.com/index/gpt-5-6/)). Do not route large-repo or multi-document work to Luna regardless of price.

6. **Terra is a dominated tier on general intelligence, but not on coding.** Artificial Analysis found "Luna and Sol are always on the Pareto frontier ahead of Terra… for any Terra effort level, there is a Luna or Sol effort level that is more intelligent at no extra cost" ([AA, GPT-5.6 has landed](https://artificialanalysis.ai/articles/gpt-5-6-has-landed)). In the coding-agent view Terra max still sits at index 62 for $2.21 vs Sol medium 61 for $2.99, so Terra max survives as a coding escalation ([AA, Claude Code vs Codex](https://artificialanalysis.ai/agents/coding-agents/comparisons/claude-code-vs-codex)).

7. **Anthropic leads raw analytical quality; OpenAI leads speed-per-quality.** Claude Opus 5 (max) tops the AA Intelligence Index at **61** ([AA, Opus 5](https://artificialanalysis.ai/models/claude-opus-5)) ahead of Fable 5 (max) at **60** ([AA, Fable 5](https://artificialanalysis.ai/models/claude-fable-5)) and Sol (max) at **59**. But OpenAI reports Sol max "comes within one point of Fable 5 while completing tasks in 61% less time at roughly half the estimated cost" ([OpenAI, GPT-5.6](https://openai.com/index/gpt-5-6/)), and AA measured Codex at **10.2 min/task** vs Claude Code at **23.6 min/task** at equal Coding Agent Index of 67 ([AA, Claude Code vs Codex](https://artificialanalysis.ai/agents/coding-agents/comparisons/claude-code-vs-codex)).

8. **Harness beats model on long-horizon tasks — this is now empirically demonstrated.** OpenAI took the *same* GPT-5.6 Sol checkpoint from **13.3% → 38.3%** on the ARC-AGI-3 public set with **6× fewer output tokens**, purely by switching to the Responses API with retained reasoning and compaction ([OpenAI, How two settings tripled our ARC-AGI-3 scores](https://openai.com/index/how-two-settings-tripled-our-arc-agi-3-scores/)). Their own conclusion: "evals rarely measure models in isolation."

9. **Deck/document generation splits by dimension.** Sol max "has the highest recorded Presentation Elo — its outputs across various file types, including PowerPoint and Excel, are the most visually attractive of any model," while Fable 5 max still leads AA-Briefcase overall on Rubric Score (56% vs 42%) and Analytical Quality Elo (1764 vs 1592) ([AA, GPT-5.6 has landed](https://artificialanalysis.ai/articles/gpt-5-6-has-landed)). Route *look* to Sol, *substance* to Anthropic.

10. **Pure repo-level code generation still favours Anthropic.** OpenAI's own table shows SWE-Bench Pro: Sol 64.6%, Terra 63.4%, Luna 62.7% vs Fable 5 80.0% and Mythos 5 80.3% ([OpenAI, GPT-5.6](https://openai.com/index/gpt-5-6/)). Terminal/agentic coding flips the other way: Terminal-Bench 2.1 Sol 88.8%, Sol ultra 91.9% vs Fable 5 83.1%.

11. **Cross-harness mixing is technically possible but officially unsupported in both directions.** Claude Code's third-party model support covers Claude on Bedrock/Vertex/Foundry/gateways only — `ANTHROPIC_BASE_URL` "changes where requests are sent, not which model answers them" ([Claude Code model config](https://code.claude.com/docs/en/model-config)). Codex can be pointed at arbitrary OpenAI-compatible endpoints via `model_providers` ([Codex config](https://github.com/openai/codex/blob/main/docs/config.md)), and Anthropic exposes an OpenAI-compatible layer at `https://api.anthropic.com/v1/` — but Anthropic explicitly says it "is not considered a long-term or production-ready solution" and it drops prompt caching, structured outputs and thinking detail ([Anthropic OpenAI SDK compatibility](https://platform.claude.com/docs/en/api/openai-sdk)). Practical mixing therefore happens over **MCP**, not model swapping.

12. **Both harnesses now ship first-class subagents with per-agent model + effort.** Claude Code subagents take `model` (`sonnet`/`opus`/`haiku`/`fable`/full IDs) and `effort` (`low`–`max`), default to background, cap at 20 concurrent and 200 per session ([Claude Code subagents](https://code.claude.com/docs/en/sub-agents)). Codex custom agents are TOML files with `model` and `model_reasoning_effort`, plus built-in `default`/`worker`/`explorer` agents ([Codex subagents](https://developers.openai.com/codex/subagents/)). Codex explicitly warns subagent workflows "consume more tokens than comparable single-agent runs."

### Harness effects: same model, different scaffold

Direct evidence that scaffold changes outcomes for a fixed checkpoint:

- **ARC-AGI-3, GPT-5.6 Sol (max):** 13.3% → 38.3% public-set score and 6× fewer output tokens, from retained reasoning + compaction alone ([OpenAI](https://openai.com/index/how-two-settings-tripled-our-arc-agi-3-scores/)).
- **Claude Code vs Codex at equal index 67:** 23.6 min vs 10.2 min, 153 vs 114 turns, 21.8M vs 13.2M tokens ([AA](https://artificialanalysis.ai/agents/coding-agents/comparisons/claude-code-vs-codex)).
- **Claude Code's own harness settings:** `ultracode` "sends `xhigh` to the model and enables dynamic workflows" — a harness-level construct distinct from model effort ([Claude Code model config](https://code.claude.com/docs/en/model-config)).
- **Codex efficiency attribution:** OpenAI credits gains to "the models, the inference systems that run them, and **the agentic harness** that connects them to tools and context" ([OpenAI price post](https://openai.com/index/advancing-the-price-performance-frontier-with-gpt-5-6/)).
- **Anthropic on scaffold dependence:** "previous Claude models struggled to play Pokémon FireRed even with harnesses that gave them additional helpful tools, but Fable 5 beat FireRed with a minimal, vision-only harness" ([Anthropic](https://www.anthropic.com/news/claude-fable-5-mythos-5)).

### When cross-harness mixing is and is not worth it

**Worth it when:** (a) you need Claude Code's rubric-style code QA (SWE-Atlas-QnA 55% vs Codex 43%) on top of Codex-authored changes; (b) you need OpenAI's Presentation-Elo-leading artifact rendering after Anthropic-drafted analysis; (c) the task is asynchronous and a second-opinion review is cheap relative to the cost of being wrong. All three exploit measured, opposite-signed strengths ([AA](https://artificialanalysis.ai/agents/coding-agents/comparisons/claude-code-vs-codex); [AA article](https://artificialanalysis.ai/articles/gpt-5-6-has-landed)).

**Not worth it when:** latency is the primary constraint (overheads are additive), when you would lose prompt caching (Anthropic's OpenAI-compatible layer drops it, and cache hit rates of 90–97% are doing heavy lifting on cost), or when a single native effort step-up would close the gap more cheaply — e.g. Codex Sol high→xhigh costs $1.10/task extra for +1 index point, far less than a bridged second agent ([Anthropic OpenAI SDK compatibility](https://platform.claude.com/docs/en/api/openai-sdk); [AA](https://artificialanalysis.ai/agents/coding-agents/comparisons/claude-code-vs-codex)).

## E. ARC-AGI-3 / "AGI-3" — exact setup and limits of generalization

**"AGI-3" is ARC-AGI-3.** It is an interactive benchmark of 2D puzzle games where agents must infer rules without instructions; the public demo set has 25 environments and scoring is efficiency-normalized against human action baselines ([ARC Prize, GPT-5.6](https://arcprize.org/results/openai-gpt-5-6); [OpenAI](https://openai.com/index/how-two-settings-tripled-our-arc-agi-3-scores/)).

### The reported OpenAI result — two different numbers, two different setups

| Attribute | Official ARC Prize run | OpenAI's own re-run |
|---|---|---|
| Exact model | GPT-5.6 Sol | GPT-5.6 Sol |
| Setting | `max` reasoning effort | `max` reasoning effort |
| Harness | ARC Prize's official generic harness — "intentionally generic… without tools or special features"; discards private reasoning after every action; rolling truncation at 175,000 characters | OpenAI's own harness built on the **Responses API**, with **retained reasoning** (pass previous response ID) and **compaction** instead of rolling truncation, at a 175,000-**token** limit |
| Score | **7.78% Semi-Private**, **13.33% Public Demo** | **38.3% public set** |
| Output tokens | Baseline | **~6× fewer** |
| Cost | ~$1.44/task, ~$25.1K total (secondary source, see caveat) | n.a. |
| Latency / time | n.a. | n.a. |
| Source | [ARC Prize, GPT-5.6](https://arcprize.org/results/openai-gpt-5-6) | [OpenAI](https://openai.com/index/how-two-settings-tripled-our-arc-agi-3-scores/) |

**Per-effort verified ARC-AGI-3 (Semi-Private), GPT-5.6 family** ([ARC Prize](https://arcprize.org/results/openai-gpt-5-6)): Sol max 7.78%, xhigh 6.99%, high 2.15%, medium 1.07%, low 0.33%; Terra max 0.80% down to low 0.01%; Luna max 0.18%, xhigh 0.02%, high 0.10%, medium 0.17%, low 0.17%.

**Where the gain came from.** Not the model — the checkpoint was unchanged. OpenAI attributes it to **harness/context management**: "after each game action, all private reasoning was discarded… the harness used a rolling truncation window, causing older actions to become invisible." With reasoning retained, "GPT-5.6 Sol spent less time thinking before each action… and was much better at learning over time and employing coherent strategies." Not reasoning effort (max in both), not sampling, not tool use (the harness has no tools) ([OpenAI](https://openai.com/index/how-two-settings-tripled-our-arc-agi-3-scores/)).

**Anthropic's competing result.** ARC Prize independently verified **Claude Opus 5 at High effort: 30.16% on ARC-AGI-3**, plus 97.5% ARC-AGI-1 and 88.3% ARC-AGI-2; at Max it scores 97.5% / 90.4% but **ARC-AGI-3 was not evaluated at Max "due to the short testing window."** Opus 5 solved five previously unbeaten environments (AR25, FT09, LP85, R11L, S5I5 at 100%) ([ARC Prize, Claude Opus 5](https://arcprize.org/results/anthropic-claude-opus-5)).

### What can and cannot be generalized

**Can generalize:**
- For any long-running agent on the OpenAI stack, use the Responses API, retain reasoning across turns/tool calls, and use compaction rather than truncation. OpenAI states these are "the same settings that we deploy in our own products" ([OpenAI](https://openai.com/index/how-two-settings-tripled-our-arc-agi-3-scores/)).
- Benchmark numbers are **model × harness × settings**. Treat any single score without a recorded harness and effort level as uninterpretable.
- Reasoning effort has an enormous, monotone effect on this class of task: Sol goes 0.33% → 7.78% from low to max ([ARC Prize](https://arcprize.org/results/openai-gpt-5-6)).

**Cannot generalize:**
- 38.3% is on the **public** task set under **OpenAI's own** implementation; the verified semi-private leader remains Claude Opus 5 at 30.16% ([ARC Prize](https://arcprize.org/results/anthropic-claude-opus-5)) and Sol's verified semi-private figure remains 7.78% ([ARC Prize](https://arcprize.org/results/openai-gpt-5-6)).
- The two headline figures are **not effort-matched** (Opus 5 at High, Sol at Max) and **not harness-matched**.
- ARC-AGI-3 measures learning in novel interactive environments. It is not a coding, writing, or document-generation proxy — the same Sol max that scores 7.78% here leads the AA Coding Agent Index at 67 ([AA](https://artificialanalysis.ai/agents/coding-agents/comparisons/claude-code-vs-codex)).
- Cost/latency figures for these ARC runs were not published on the primary ARC Prize result pages fetched here → **n.a.** for authoritative cost and time.

## F. Proposed routing policy (10 rules)

Optimized for **latency first, quality second, cost third — except executive/CPO/CTO deliverables, where quality is first.**

1. **Harness settings before model choice.** On the OpenAI stack always use the Responses API with retained reasoning and compaction; on Claude Code keep effort constant within a session to preserve the prompt cache. This is free and worth up to 3× on long-horizon tasks ([OpenAI](https://openai.com/index/how-two-settings-tripled-our-arc-agi-3-scores/); [Anthropic effort docs](https://platform.claude.com/docs/en/build-with-claude/effort)).

2. **Interactive default = GPT-5.6 Sol (medium) in Codex.** 4.57 s TTFT, Coding Agent Index 61, 5.2 min/task — the fastest configuration that stays above a production quality bar ([AA Sol medium](https://artificialanalysis.ai/models/gpt-5-6-sol-medium); [AA](https://artificialanalysis.ai/agents/coding-agents/comparisons/claude-code-vs-codex)).

3. **Volume, subagents, extraction, tests, tiny fixes = GPT-5.6 Luna (high).** $0.19/task in Codex at index 51, 162 tok/s, 8.87 s TTFT. Drop to Luna medium only for classification-grade work ([AA](https://artificialanalysis.ai/agents/coding-agents/comparisons/claude-code-vs-codex); [AA Luna high](https://artificialanalysis.ai/models/gpt-5-6-luna-high)).

4. **Never send >100K-token context or multi-document synthesis to Luna at any effort.** MRCR 8-needle 41.3% ([OpenAI](https://openai.com/index/gpt-5-6/)).

5. **Escalate one effort step before changing tier.** Sol medium→high buys +3 AA index points and +3 coding index points for +$1.15/task; that is cheaper and lower-risk than a tier or harness change ([AA](https://artificialanalysis.ai/agents/coding-agents/comparisons/claude-code-vs-codex)).

6. **Hard debugging, architecture, root-cause and code review = Claude Opus 5 (xhigh) in Claude Code**, run asynchronously. Index 67 with the best measured SWE-Atlas-QnA (55%), but budget 23.6 min/task — never on an interactive path ([AA](https://artificialanalysis.ai/agents/coding-agents/comparisons/claude-code-vs-codex)).

7. **Novel-problem / unfamiliar-environment reasoning = Claude Opus 5 (high).** Verified ARC-AGI-3 30.16%, ~4× the next model ([ARC Prize](https://arcprize.org/results/anthropic-claude-opus-5)).

8. **Executive / CPO / CTO deliverables — quality first, two-pass.** Draft and analyze with **Claude Opus 5 (max)** (AA Intelligence Index 61) or **Fable 5 (max)** (AA-Briefcase Analytical Quality Elo 1764); render the final deck/doc/spreadsheet with **GPT-5.6 Sol (max)** (highest Presentation Elo). Ignore latency and cost on this path ([AA Opus 5](https://artificialanalysis.ai/models/claude-opus-5); [AA article](https://artificialanalysis.ai/articles/gpt-5-6-has-landed)).

9. **Buy latency with money before buying it with quality.** When a fast path must stay high-quality, use Fast mode — up to 2.5× faster at 2× price with "no change in intelligence" on GPT-5.6 Sol, and ~2.5× default speed at 2× price on Opus 5 — rather than dropping a tier ([OpenAI price post](https://openai.com/index/advancing-the-price-performance-frontier-with-gpt-5-6/); [Anthropic, Opus 5](https://www.anthropic.com/news/claude-opus-5)).

10. **Parallelize instead of deepening, and only when workstreams are independent.** Use Codex subagents / Sol `ultra` (4 agents) or Claude Code background subagents for exploration, tests, triage and review; avoid parallel write-heavy fan-out, which OpenAI warns "can create conflicts and increase coordination overhead." Do not add a cross-harness MCP hop on any latency-sensitive path ([Codex subagents](https://developers.openai.com/codex/subagents/); [Claude Code subagents](https://code.claude.com/docs/en/sub-agents); [OpenAI](https://openai.com/index/gpt-5-6/)).
