# Project context

This is an empty template. Put live project records in approved private storage,
outside code repositories. This folder does not synchronize itself.

Record the current outcome, scope and acceptance conditions here. Link only the
resources needed for this project; repositories are optional. A project can link
several repositories, or only documents, folders and chats.

- `STATE.json`: current coordinator, revision, linked resources and task attempts.
- `DECISIONS.md`: accepted decisions, rejected alternatives and supersessions.
- `KNOWLEDGE.md`: sourced findings worth retaining beyond the current phase.
- `returns/`: immutable reports for individual worker attempts.

Keep the storage binding and account/realm selection in private local instructions
or the authorized task brief. Never put real paths, private links, records or output
from the local checker into a public release merely to demonstrate setup.
