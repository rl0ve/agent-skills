# Research Reports

Deep research and decision briefs with evidence, counterarguments and a few visuals
that explain the findings. The workflow covers synthesis and the reading package;
specialist tools handle diagrams, charts, documents or an optional motion overview.

Use it for strategic research, meeting preparation, a substantial source-backed
report or a continuation of an existing research package. For issue-by-issue reviews
and improvement proposals, use Clear Assessment Guides. For comparisons among
implemented UI versions, use Visual Version Review.

The default is one primary document format: PDF for finished reading or DOCX for
substantive editing, unless the user specifies another medium. Producing both requires
an explicit request. A short meeting aid can accompany a requested deep report; a
visual guide or HyperFrames-style overview needs a distinct benefit.

The skill deliberately considers explanatory visuals for the important findings:
relationships, cross-team handoffs, structural change, mechanisms and quantitative
patterns. It does not require a diagram in every section or a video in every package.
It preserves source distinctions, unit/period differences and the boundary between
an observed result and a proposal.

## Install

```bash
codex plugin add research-reports@rl0ve-agent-skills
claude plugin install research-reports@rl0ve-agent-skills
```

Example: “Research the competing explanations for this adoption pattern. Challenge
my thesis and prepare a substantial report plus a one-page meeting aid. Use the
few visuals that clarify the argument; consider a short motion overview only if it
helps me understand the mechanism.”
