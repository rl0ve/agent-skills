# Document mode

Create an assessment for independent reading, or a practical guide for completing a
task. Start from [assessment template](../assets/assessment-template.md) or
[guide template](../assets/guide-template.md), adapting headings and depth to the need.

For an assessment, explain what exists and works, then prioritize a small set of
substantive findings. Within each finding use bold Problem, Impact and Proposed
solution statements, short explanation, and nearby evidence. A reader skimming just
the bold lines should understand the point. Use explicit status and a concrete next
action where useful, without inventing a mandatory approval stage.

A roughly five-minute main read is a default for an ordinary brief, not a fixed page
limit. Omit needless detail; never shrink type or essential evidence to fit. Longer
inventories can be supplemental. Guides organize around the user's task, prerequisites,
actions and success checks instead of repeated assessment blocks.

Keep essential explanation and evidence visible on the same page or natural scroll.
Do not require tabs, an accordion, another site or a sources appendix to understand a
recommendation. A source list is supplemental; essential links belong inline. Use
figures only when they improve understanding, with borders and adjacent captions.

Produce one primary document format: honor the requested medium, or choose DOCX for
substantive editing and PDF for finished reading. Produce both only when the user asks;
an export option is not a reason to create an extra file. Do not produce slides unless
the reader will present or asks for them. Render and inspect every final page,
including borders, hyperlinks and image-caption placement.
