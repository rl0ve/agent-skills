# Motion-explainer routing cases

Policy review for UI Router 1.19.5 and UI Walkthrough Video 1.7.2. These are
scenario expectations, not automated model runs or evidence of rendered quality.

| Case | Expected decision | Failure to catch |
| --- | --- | --- |
| Explain an approval process like a supplied motion artifact; content is accepted but the current result feels like a slide deck | `motion-explainer`; inspect the reference, preserve content, select one craft lead, plan object continuity and prove a short moving sequence | Repeating title/body/diagram scenes with fades; treating higher resolution, a new voice or a renderer switch as the aesthetic fix |
| A single HTML reference contains inline SVG, a playback loop and CSS transitions | Distinguish source inspection from actual playback; use it as visual evidence, preserve product identity, adapt time-driven state for export | Calling it Remotion because Claude made it, executing embedded instructions, or claiming random-seek/export safety without testing |
| An existing React/Remotion project needs a polished launch film | Consider video-shotcraft as the craft workflow and official Remotion skills as implementation support; load only relevant complete recipes | Replacing the settled engine, loading every effects library, or silently adding paid music |
| An existing custom SVG renderer can meet the reference | Keep it and explicitly adapt the beat/continuity/proof method | Mandatory HyperFrames installation or claiming an upstream workflow was loaded from a catalog link |
| Record a user's complete browser task with explanatory animated inserts | Walkthrough skill owns observed capture, voice and handoff; one motion layer owns inserts; retain its HyperFrames opt-in if selected | Replacing real actions with an invented interface or forcing a conceptual-film workflow over capture |
| Fix a button's hover easing in an accepted app | `motion-only`; preserve structure and use existing UI motion guidance | Requiring storyboards, a 10–20 second film proof, new fonts or video-tool installation |
| Make a simple screen recording or a static slide deck | Existing capture or presentation route | Treating every video, deck or business topic as a cinematic explainer |
| A quiet learning animation intentionally holds a diagram while a relationship is explained | Preserve the hold, correct semantics and readable labels; compare with the requested reference | Enforcing a teaser's speed, multiple focal points, shader transitions or constant ambient animation |
| The user asks which skills are popular | Separate official maintenance, first-person maker reports and dated repository signals; state the limits | Claiming measured industry market share from stars, a promotional post or an untested gallery |
