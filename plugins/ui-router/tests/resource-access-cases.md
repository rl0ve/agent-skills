# Resource access policy cases

Reasoning fixtures for 1.16.6, with expected decisions. These are policy checks,
not automated agent runs or a comparative design benchmark.

| Case | Expected decision | Failure to avoid |
|---|---|---|
| A free-only React component task has a working 21st CLI and one free retrieval left. | Search within the free route, select a candidate, use the allowance if needed, then inspect source/terms and validate adoption. | Require Builder or configure another integration before using already adequate access. |
| A user wants current Motion documentation and has no Motion account. | Use the free docs server or public docs; load the selected official skill when useful. | Require signup or Motion+ for public documentation. |
| A Motion skill lists a free easing tool, but the connected server only exposes search. | Use the live tool list, explain the relevant limit and continue through available docs/implementation. | Claim easing generation ran or fabricate the missing tool's result. |
| Motion search returns a premium carousel description and public demo, with no source tool. | Label the source gap; view the public demo if relevant or build an original implementation using accessible docs. | Claim premium source retrieval or treat a metadata result as verified component behavior. |
| A 21st Builder member has `aiGenerationEnabled: false`. | Use entitled component retrieval and the user's coding agent; hosted generation requires separate access. | Assume unlimited components include AI credits, or repeatedly retry denied generation. |
| The user already has authorized paid reference access and asks for no new spend. | Use the existing entitlement within the task; keep strict free-only wording distinct. | Buy a replacement or treat an existing available connector as inaccessible. |
| A free MIT workflow calls a paid image model. | Identify the separate generation cost and honor the existing spending authorization. | Treat a free skill license as permission for paid generation. |
| A settled page needs a one-line spacing correction. | Make the scoped correction with existing tools. | Run a resource survey, create accounts or install Motion because UI work is involved. |
