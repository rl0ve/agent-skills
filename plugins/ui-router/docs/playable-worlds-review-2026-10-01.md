| Finding | Decision |
| --- | --- |
| Encounter decisions, level landmarks, camera readability and audio lifecycle | Adopt precise specialist routes with scope boundaries; adapt the shared choice/consequence/recovery principle. |
| Combat defaults and strict flat-plane level geometry | Conditional within the upstream action-game scope; do not impose them on calm learning or architectural/XR worlds. |
| Playable-game testing | Already covered; keep real controls, deterministic review states and save/retry checks. |
| Score-to-target and blind-judge workflow | Reference only; self-scores do not prove user engagement or learning. Do not import automatic delegation, indefinite polishing or publishing authority. |
| Fullscreen ChatGPT sidebar apps and conversation panels | Conditional delivery option; trial a real scene and state lifecycle before platform commitment. |
| Model choice from likes or author claims | Reject as a benchmark; Work Router owns model routing. |

Policy cases: a calm language mystery triggers connected choices and changed-context
retrieval, without combat or forced speech; a static product card does not trigger
a game-loop redesign; an existing standalone world gains a host adapter only after
a real host trial. This is a policy walkthrough, not a comparative user study.

## Follow-up: assets, device input and runtime decisions

Adopt scene-audio evaluation and early specialist-input proofs as reusable methods.
Keep MiniMax Design, Higgsfield and ElevenLabs as conditional asset candidates;
no same-brief quality comparison was run. The workspace, underlying model, export,
billing route and commercial media rights are separate decisions. Creator tool
mentions are research leads; the date and production recipe for Meng's use of these
services were not verified in this follow-up.

Meta's web input guide and Virtuix's PCVR documentation support different delivery
paths. An XR browser does not establish treadmill integration. OpenAI's official
September 29 Decisions announcement supports a conditional bounded-choice route,
with preview access and task benefit still needing verification. The selected
public sources are linked in interactive-worlds.md.

Policy cases: a voiced calm adventure with ambient loops triggers a small audio
comparison and in-scene mix review; a static dashboard does not. A required
treadmill walkthrough triggers a driver/SDK and locomotion proof; an ordinary
mouse-controlled decorative scene does not. Context-sensitive NPC choices can
justify a bounded runtime trial; exact object placement and assessment still use
ordinary rules. This is a policy review, not hardware or model benchmarking.
