Find new skills safely

Use each source for the question it answers: broad category discovery, weekly momentum, curated vetting, known-skill lookup, then final upstream verification.

Default path: Skillselion to discover, Skill Leaderboard to scan momentum, curated sources to vet, skills.sh or claudeskills.info to look up a known target, and GitHub to verify before any install.
