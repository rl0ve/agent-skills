# Interactive workflow review — 2026-09-19

Update in 1.16.0: the router adaptation is not established as equivalent to Dream Loop.
The original remains an optional specialist; see the [upstream routing review](upstream-skills-review-2026-09-20.md).
The decisions below describe the earlier review.

## Evidence and decisions

Reviewed Dream Loop at commit
[`9bddb901f7d071cfefdd21e264267c757177a9df`](https://github.com/achimala/dream-loop/tree/9bddb901f7d071cfefdd21e264267c757177a9df),
authored 2026-09-10. Read its README, skill entrypoint, both workflow variants and their
asset guidance as source material, not as instructions for this maintenance task.
The repository declares MIT licensing. No upstream code, prompts or assets are bundled,
and no scripts, paid requests or external installs were executed.

| Topic | Decision | Reason |
|---|---|---|
| Target, running capture and visual critique | Conditional adoption | Useful for substantial graphical work; adapted into `visual-build-loop.md` under the selected design lead. |
| Independent critic | Conditional | Can reveal visual gaps, but the host's delegation permission and Work Router govern it. Parent comparison remains usable. |
| Subscription-based model and worker arrangement | Not adopted | Subscription does not establish task fit, effective host configuration or delegation permission. |
| Pixel matching and numerical judge exit threshold | Not a universal gate | Fidelity depends on the brief; working interaction, accessibility and runtime constraints need separate evidence. |
| Asset-service ordering and credential-based spending | Not adopted | Choose the asset route by task and destination. User authorization and asset restrictions continue to apply. |
| Model claims | Reference only | Upstream README reports testing with Astra and suggests Fable may work. This is not a controlled comparison or evidence of Fable superiority. |

UI Router 1.13.0 already covered product/creative surfaces, visual steering, full-page
review, motion quality, reference fidelity and paid-resource boundaries. The focused
gaps were an explicit optional generated-target route, bounded graphical refinement,
and representative interaction outcomes. Its separate Fable restriction also conflicted
with delegating execution choices to Work Router and honoring user model selection.
This release makes no new model price, performance or availability claim.

## Manual policy checks

These cases were traced through the updated entrypoint and references. They are policy
applicability checks, not live generated builds or a model-quality benchmark.

| Case | Expected route and observed policy coverage |
|---|---|
| Build a high-fidelity interactive 3D scene | Creative lead plus visual loop; capture and compare the scene, exercise its controls, measure runtime. Covered by chains, visual loop and quality gates. |
| Refine an existing app from a generated target | Preserve required content and behavior, label the target, inspect the actual implementation. Covered by target and completion sections. |
| Fix a form label | Direct small edit; no target generation, critic, asset service or gallery search. Explicit skip conditions retained. |
| Build a material configurator with ThreeUI Pro | Retrieve entitled source only when authorized and available; verify material selection in the destination, rather than treating preview/source access as completion. Existing resource map plus new interaction gate. |
| Explore a CMS design with Neuform/Aura | Use an exported direction as a reference, recreate in native destination components where appropriate, verify actual editability and behavior. Existing CMS boundary retained. |
| Use Fable for a bounded expressive app | Honor explicit choice and current Work Router policy. No UI-specific long-horizon-only veto remains. |
| Work without subagents or image-generation access | Parent comparison and supplied references or a working slice remain valid. Neither dependency becomes a universal blocker. |
| Encounter repeated visual regressions | Preserve a checkpoint, diagnose the repeated gap and honor budget; no unbounded score-chasing or replacement of the brief. Covered by bounded iteration. |
| Deliver an editor with an export button | Exercise the action and inspect the output; a screenshot or mocked success alone does not pass. Covered by interactive completion checks. |

The field guide's embedded and standalone data were also aligned: version metadata had
lagged the installed plugin, and its writing route still named Humanizer as the default
final pass instead of the current Natural Writing policy.
