# Upstream specialist routing — 2026-09-20

## Decision

UI Router selects and coordinates; a selected specialist supplies its detailed method.
Prefer the complete upstream procedure when that distinctive method fits. Load it for
occasional use, install selected complete folders for repeated use within authorization,
and adapt small shared principles into the router. A material rewrite remains a named
adaptation until comparable evidence supports an equivalence or improvement claim.

This corrects 1.14.0's preference for the router's shortened Dream Loop adaptation.
That source review supported borrowing a method, but did not establish equivalent
results. Dream Loop is now an explicit optional specialist. The lighter fallback
remains useful without replacing the selected workflow's rubric or iteration method.
User and host constraints continue to govern models, delegation, spending and scope.
No comparative build is required just to use a skill normally.

## Manual applicability checks

These are policy walkthroughs, not model-generated builds or a comparative benchmark.

| Case | Expected and checked behavior |
|---|---|
| User explicitly requests Dream Loop for a detailed 3D scene | Load the original entrypoint and the chosen variant's required references; preserve detailed craft where compatible. No silent substitution of the router summary. |
| User chooses the lighter loop for a bounded visualization | Use and label the router adaptation. Its limits apply to that route only; do not claim upstream equivalence. |
| A cinematic scroll world fits a Meng specialist | Select the exact upstream skill and required support files; the broad bundle alias alone is insufficient. |
| A task needs one capture skill once | Read the selected workflow as task context; no mandatory global installation or whole-repository load. |
| User authorizes a recurring-use skill install | Preserve the complete selected folder, required dependencies, notices and provenance; verify availability separately. |
| Existing local specialist has custom edits | Compare upstream changes before refresh; do not silently overwrite the customization. |
| Upstream requires unavailable or disallowed delegation or paid generation | Identify the conflict, retain compatible craft, and label any material adaptation. A fallback cannot be called completion of an explicitly required method. |
| A form label needs a small correction | Remain direct; no external skill search, image-generation loop or comparative trial. |
| A router adaptation is proposed as a superior replacement | Compare the same representative brief, assets, constraints and budget before making the claim. No claim is made by this release. |
