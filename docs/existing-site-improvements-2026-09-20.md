# Existing-site improvement lessons — September 20, 2026

A conditional UI Router reference addresses revisions that improve legibility but
lose useful content, established messaging, brand continuity or successful interaction.
An attractive screenshot is insufficient evidence of a better complete experience.
This record contains generic lessons, not project source material or private feedback.

## Scope decisions

- Adopt: compare purpose, prominence and actual behavior; preserve strong content and
  expression while fixing observed problems; verify important image subjects during
  motion and at relevant widths; withdraw unsupported scoring conclusions.
- Conditional: an explicit rebrand can replace old visual choices. Preservation is
  not an instruction to override a user's approved new direction.
- Already covered: native CMS/editor persistence, reduced motion and destination
  fidelity; Astra selection when the work demands it. These are linked, not duplicated.
- Avoid: a new broad skill, third-party runtime, universal service-site template,
  mandatory redesign inventory for a mechanical edit, or unmeasured conversion claims.

## Independent policy exercises

An independent Astra reviewer checked four supplied scenarios against the proposed
instructions. These are policy exercises, not comparative website experiments.

| Case | Expected and observed decision |
| --- | --- |
| Service-site revision loses practical information despite polished visuals | Keep original brand/content, fix the demonstrated readability problem, check the actual CMS, reject the unsupported high score. |
| Explicit cinematic rebrand with approved copy | Honor the new direction while preserving essential transactions and support; do not force the old palette. |
| Typo and phone-button contrast correction | Make the narrow change without delegation, broad inventory or a new copy handoff. The entrypoint exception resolves the initial procedural friction. |
| Revision loses galleries, entrances, interactive imagery and disclosures, and crops a person | Restore or adapt observed successful behavior; correct the crop; test motion and the reduced-motion alternative before claiming expression recovered. |
